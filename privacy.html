Privacy Policy

Last updated: November 17, 2026

Application

Rclone Backup is a personal Windows application used to copy files from an authorized Google Drive folder to a local computer.

Information accessed

The application accesses Google Drive files and folders authorized by the account owner, using the Google Drive API through rclone.

How information is used

Information is accessed only to perform personal backup operations. Files are copied to local storage on the user's computer.

Data sharing

The application does not sell, share, or distribute personal information or backed-up files to third parties.

Data storage and security

Backup files are stored locally on the user's computer. OAuth credentials are used by rclone to access Google Drive. The user is responsible for protecting the computer and local backup data.

Contact

For privacy questions, contact the application owner through the GitHub repository.
